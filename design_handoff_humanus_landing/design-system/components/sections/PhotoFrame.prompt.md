Frames real photography in Humanus shapes; omit src to show a clearly labelled placeholder (never fake imagery).
```jsx
<PhotoFrame src="assets/photos/kine-1.jpg" alt="Sesión de kinesiología" shape="organic" ratio="1 / 1" />
<PhotoFrame placeholder="Foto: entrada del establecimiento" ratio="3 / 4" />
```
Use organic/arch sparingly (1 per section). Hover gives a slow 3% zoom.
