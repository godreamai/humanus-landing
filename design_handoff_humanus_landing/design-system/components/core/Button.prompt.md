Pill-shaped action — the main conversion element; use primary + whatsapp icon for every "consultar" CTA.
```jsx
<Button size="lg" icon="whatsapp" waMessage="Hola, quisiera hacer una consulta sobre los servicios de Humanus.">Consultanos por WhatsApp</Button>
<Button variant="secondary" href="#servicios" iconRight="arrow-right">Conocé nuestros servicios</Button>
```
Variants: primary (azul), secondary (celeste outline), ghost (text), light (white on blue bands), outlineLight (outline on blue). Sizes sm/md/lg (40/48/56px). One primary per view region.
