Brand lockup for headers and footers: the official "h" mark + typeset HUMANUS wordmark.
```jsx
<script>window.HUMANUS_ASSET_BASE = '../../assets/logo/'</script>
<Logo size={60} />
<Logo tone="white" tagline={false} />
```
Set window.HUMANUS_ASSET_BASE to the relative path of assets/logo/ from your page. The wordmark is typeset — swap for an official lockup file if one appears.
